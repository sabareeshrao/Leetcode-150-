# Learning Workflow Rules

These rules apply to every future day in this repository.

1. Language: Java only unless explicitly changed.
2. Explanations: English only.
3. Each new day starts with questions/tasks only.
4. Do not include solutions, answer code, hints that reveal the solution, or completed outputs in the initial task file.
5. The learner attempts the tasks first.
6. Only after the learner explicitly asks for the answer/solution should a solution be written.
7. Store the task and solution separately when a solution is requested.
8. Keep each day beginner-friendly and small. Build prerequisites before assigning the actual LeetCode problem.
9. Continue from the latest repository state when starting from another chat or branch.
10. Do not change this format unless the learner explicitly requests a change.

Standard flow:

```text
DAY TASKS (questions only)
        |
        v
LEARNER ATTEMPT
        |
        v
LEARNER ASKS FOR SOLUTION
        |
        v
SOLUTION + EXPLANATION
        |
        v
NEXT DAY
```
